- 取证：`gallery.html` 的「报表结果」是 Univer 画布；Univer 与 Excel 同款——**数字**放不进列宽就整格画 `####`（文本只是裁剪）。26 份实例里只有 `tobacco-output`（卷烟产值表）命中：模板列宽 45px，`#,##0.0000` 要 46-52px，一屏 272 格井号。其余 25 份 0 格。

## 安装 dkitchen（多 agent 工作流 + ding CLI）

- 来源：GitHub 917Dhj/dkitchen（MIT，创建 2026-10-10，5 stars，PyPI 0.4.0）。安装前做了源码审计：wheel 只有 5 个模块、唯一运行依赖 `websocket-client`，无 post-install 钩子（setuptools.build_meta，无自定义后端）；**无 `shell=True`/`eval`/`exec`**，全部 `subprocess.run([...])` 列表参数；出网只有 `ws://localhost/`（Codex App Server 本地 socket）；状态写 `$XDG_STATE_HOME/ding/`（0700）、配置读仓库根 `.dkitchen.toml`。Claude Code 插件清单：1 个 skill（`setup-dkitchen`）、**0 hooks / 0 MCP / 0 agents**，always-on ~49 tok。
- 安装结果：`brew install pipx` 在沙箱里失败（`sandbox_apply: Operation not permitted`，同 2026-10-02 的嵌套 sandbox 限制）→ 改用隔离 venv：`~/.local/venvs/dkitchen`（Python 3.13.12）+ `~/.local/bin/ding` 软链；`ding 0.4.0` 可用。Claude Code 侧：`claude plugin marketplace add 917Dhj/dkitchen` + `claude plugin install dkitchen@dkitchen`（user scope，enabled）。
- 两个未打通的外部依赖（都要在真实终端做）：① `gh` **未登录**（`gh auth status` 报未登录）；② Codex App Server 守护进程起不来——`codex app-server daemon start` 在工具会话里报 `failed to invoke ps ... Operation not permitted`，根因是沙箱把 `ps` 挡了（`ps -p 1` 直接 operation not permitted，连 `dangerouslyDisableSandbox` 也没绕开）。`/tmp/codex-daemon-501` 因此没有 socket，`ding board` 报 `Found 0 App Server sockets`。
- macOS 注意：`ding board` 的「没用 ding 启动的长任务」审计依赖 `/proc`，macOS 上会打一行 warning（非致命）。
