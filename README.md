# Report Studio · 需求 → 模板 → 结果

Report Studio 是基于 React + TypeScript + Vite 构建的智能报表工作台，提供从「一句话业务需求」到「结构化查询与模板编排」再到「多格式打印与分析结果」的全链路闭环体验。

## 核心特性

1. **三步走报表编排**
   - **明确需求与数据源**：支持示例数据、CSV/TSV 自定义文件上传，以及 PostgreSQL、MySQL、SQLite 数据库连接与库表 SQL 采样探测，提供字段类型与角色推断画像。
   - **自动给出可选模板**：根据字段重合度、形态匹配及业务描述自动推荐 6 种预设模板（交叉表、分组表、趋势表、排名表、明细清单等），支持保底的「按需生成」。
   - **可调整的选项**：直观配置六大语义报表形态（明细/分组/交叉/趋势/排名/对比）、行维度排序、度量与聚合函数（求和/平均/最大/最小/计数）、行末小计与总计行开关，并支持通过自然语言对话规则快速补充调整。

2. **多步骤归因分析（§8 L2）**
   - 将「为什么指标下降了」自动拆解为受控的多步查询链：全库基准对比 → 核心维度拆解 → 负向贡献细分下钻。
   - 区分客观现象（observed）与算术归因贡献度（computed），并给出每步可复现的 SQL 语句与因果局限说明。

3. **版本管理与自动化（§8 L3）**
   - **语义版本**：支持保存带有口径哈希指纹、模板 rev 与业务备注的快照，并提供多版本间口径差异对比。
   - **定时执行**：支持按日、按周、按小时配置执行计划，支持立即执行、暂停/启用管理。
   - **异常体检提醒**：支持自定义变动率阈值体检，检测指标波动并触发预警。

4. **模板设计器与运行中心**
   - **设计器**：可交互的单元格排版台，支持字号、加粗、水平/垂直对齐、边框修饰及公式格（ƒ）属性检查，改动即时写回模板修订版本。
   - **运行中心**：完整记录报表历史运行批次，提供打印视图与数据表格双模预览，支持 CSV、XLSX、HTML 等多种产物下载。

## 技术栈与快速开始

- **技术栈**：React 18、TypeScript、Vite
- **样式规范**：「墨与纸」设计系统（暖纸底色、深蓝墨锚点、琥珀强调色）
- **本地启动**：
  ```bash
  npm install
  npm run dev
  ```
- **生产构建**：
  ```bash
  npm run build
  ```
