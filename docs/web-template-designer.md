# Web 报表模板设计

报表的可编辑定义是 JSON 文件，Univer 负责显示和编辑模板，Rust 引擎负责取数、
计算公式、按主格关系扩展和分页。复杂示例的定义是
[`complex-master-expansion.json`](../examples/tutorial/complex-master-expansion.json)，
数据是 [`complex-master-sales.csv`](../examples/tutorial/complex-master-sales.csv)。

## 操作流程

1. 点击「新建模板」，或在顶部选择已有 JSON。打开模板不需要数据文件，也不会先运行公式。
2. 在「数据源与数据集」中上传数据文件，填写数据集名称、文件名和编码，点击「添加数据集」。
   文件名必须与上传的文件一致。现有数据集可编辑或删除。
3. 在 Univer 选中模板格，在右侧「公式与主格」选择内容类型，填写文本或报表公式、
   扩展方向、左主格、上主格及合并行列数，然后点击「应用单元格定义」。
   公式可以不带开头的 `=`；直接在画布输入时用 `=` 区分公式和文本。
4. 样式、边框、行高、列宽和网格大小使用右侧相应面板。主格格号始终使用扩展前的模板地址。
5. 点击「保存模板 JSON」下载当前编辑内容；重新选择该 JSON 可以继续编辑。
   「存入模板库」把当前定义提交到服务端，服务端按现有资产格式存为 RPX。
6. 点击「运行生成报表」。前端把当前 JSON、上传的数据文件和参数提交给 Rust 引擎。
   成功后显示只读的运行结果；点击「模板设计」返回原始模板，继续修改并重新运行。
7. 运行后可以进入「图形与打印预览」打印或保存 PDF，在「文件 → 导出」生成 Excel、CSV。

侧栏尚未应用的单元格或数据集修改会阻止运行和保存，需先应用、保存或取消。
数据文件缺失、公式错误等运行失败会显示原因，模板内容保留。JSON 保存数据集引用，
数据文件需另外保存；重新打开页面后要重新上传。

## 最小主格示例

新建模板后设置两个单元格：

| 模板格 | 内容类型 | 公式 | 扩展方向 | 左主格 |
| --- | --- | --- | --- | --- |
| A1 | 报表公式 | `to(1,3)` | 纵向扩展 | 留空 |
| B1 | 报表公式 | `A1*10` | 不扩展 | `A1` |

运行后前三行分别是 `1 / 10`、`2 / 20`、`3 / 30`。保存的模板仍然只包含这两个
公式格，而不是扩展后的结果格。

复杂示例在原始 **12×11** 模板中设置三层纵向和两层横向主格，运行得到 **23×25**
的报表。选择 `C6` 可以查看其公式 `&D6` 和左主格 `D6`，验证主格可以位于右侧。
更多关系与核对值见[复杂示例说明](../examples/tutorial/complex-master-expansion.md)。

## SQL 数据源

数据集类型选择「SQL 数据集」，填写数据源名称和 SQL 查询，再保存数据集。
数据源名称对应服务端注册的数据库连接；连接由管理员通过启动参数
`--datasources <path.json>` 配置，Web 当前提供模板中的数据源引用和 SQL 编辑。
格式见 [`datasource.rs`](../crates/rpx-server/src/datasource.rs)。

原生 RPX 文件可以运行、预览和入库。需要继续在 Web 编辑时，请保存并使用 JSON 定义。
模板库目前提供入库和参数元数据接口，Web 的重新编辑入口是打开保存的 JSON。

模板设计时保留 Univer 的画布输入与公式栏。格式和结构操作通过报表面板修改，
防止原生电子表格的行列移动使主格地址、报表公式与 JSON 不一致。
