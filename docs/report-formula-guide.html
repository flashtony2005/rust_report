三个必记（都是反直觉的）
  1. 这不是 Excel：sum(B2:B4) = 100（=B2，区域不聚合， 只取操作数 1）。求和要写 ds1.sum(col)（操作数求值为 List 时才聚合）。
  2. 扩展格只有 4 个：ds.select / ds.group / ds.filtercross / ds.plot 才是 「可扩展」公式；sum/count/avg/max/min 不是—— sum(ds1.select(qty)) 的外层是假（is_extend 不向参数透传）。
  3. 格号优先于函数名：解析第 9 步（格号）排在第 10 步（函数）之前 ⇒ B2(1) 是「对 B2 取偏移」，不是函数调用。

2. 语法骨架

2.1 三层参数分隔（; > , > :）

层级分隔符用途（以 select 为例）
最粗;多排序键段：select(x, cond; key1, key2)
中,函数参数：select(选列, 过滤, 限量, 去重)
最细:次序/区间：select(dept:1)（去重次序）、B2:B4（区域）
⚠ 固定次序，不是「谁先出现」：ParamParser 按 ';' → ',' → ':' 逐级判 getType() ⇒ a:b,c 的类别是 ',' 不是 ':'；只有整串没有 , 也没有 ; 时 : 才成为类别。这直接决定 ValueList 的 is_extend： [a:b,c] 为真、[a:b] 为假。
词法两条：① . 不是分隔符 —— ds1.select 是一个原子（靠 indexOf('.') 切数据集名）； ② ; 是参数级分隔符，永不作为 token 出现在表达式内部。 运算符两字符优先：== != >= <= && ||。

4. select 参数矩阵（最常用公式）

参数位字段语义实例（取自 cross 夹具）

2过滤表达式条件过滤ds2.select(item, amount>=2000)、emp_id==A3

6. extend_mode 与扩展格判定

6.1 四态（运行时改写，不是按声明值）

声明 extend_mode码计算态实际生效值分布
（缺省 DEFAULT）1618（运行时自动升为竖向）每行一个
"vertical"1818每行一个
"horizontal"1919横向铺开
NONE1717（由其他列驱动）整列 List 塞一格
  • extend=18 行数公式：计算态行数 = 模板行数 +（数据集行数 − 1）；锚点占第 1 个数据行， 其余 N−1 行插入（3 行模板 + 4 行数据 → 7×4）。
  • 横向边界：单独一行用 19 时列数恒增 N−1；但 19 与 16/18 同行时列数不增 （竖向扩展已把该行登记为可扩展行，横向被吞）。
  • ⛔ 必须复刻 leftHead/topHead 拓扑判定，否则「声明 16」与「声明 18」 行为分叉。

6.2 is_extend 真值表（谁会成为扩展格）

节点is_extend依据
Constant / @参数（值是 List）真值 instanceof List
DS 函数 select/group/filtercross/plot真四个类显式覆写
普通函数 sort/sublist/to/split真四个类显式覆写
格引用 B2/$B2 / ds1.col / UnknownSymbol假无重写
ValueList（[…]/[1,2]/[a,b:c]）真顶层类别 ≠ ':'
[1:3] / Link（:）假Link 恒假（唯一覆写）
其余全部运算符 / 其余 120 普通 + 11 DS 函数（含 sum/count/avg…）假无重写

三条传播规则：R1 运算符 = 左 || 右；R2 SpecialFunction（{…}/x[…]） = 只看左；R3 Function = 自身，不向参数透传。

头号回归：sum(ds1.select(qty)) ⇒ 外层 Sum 假、 内层 DSSelect 真，但 R3 不透传 ⇒ 整体 is_extend = false。 ⛔ is_extend 不能用「是不是 DS 函数」近似（isDSFunction 的传播规则 恰好相反：向参数透传）。

7. 求值语义（不是 Excel，六条铁律）

公式实测值结论
sum(B2:B4)100（=B2）区域不聚合（只取操作数 1）—— M2 硬约束：禁止 Excel 式区域求和
avg(B2:B4)Double(120)（=B4）avg 的操作数与 sum/max/min 不对称（sub0/sub1 互换）
max(B2:B4) / min(B2:B4)100 / 100（=B2）同上，区域形态走单格 else 分支
ds1.sum(qty)450操作数求值为 List 才聚合
ds1.sum(qty)（数据集被扩展格引用）100/200/150（随行）被引用 ⇒ ds.current 被灌成 Row ⇒ 逐行退化
ds2.sum(qty)（未被引用）450/450/450未被引用 ⇒ 停在 RootGroup ⇒ 全量聚合
空表 avg vs sumnull vs Double(0.0)avg 全空 = 0.0 且先于除法判定；sum 空表 = 0.0

⛔ 类型即契约：Integer/Long/Double/String/List 原样区分， 不得统一提升为 f64（expected.json 的 type 字段就是断言依据）。

8. 诚实清单（当前不支持 / 已知偏差）

#写法本切片行为影响
2@多选参数（值为 List）取 false（拿不到参数值）真实分叉：多选参数报表扩展行数算错（7+2 夹具零覆盖）
3数据集名前缀不存在不校验，形态像就算 DS 函数拼错的 ds 名被当成 DS 函数
4列名形如格号（qty1）按形态判定被误判成格引用（is_extend 两边都假，求值期必错）
5嵌套 ; , : 参数树只建模顶层一层is_extend 不受影响；求值期受影响
7$[…]当成格引用求值期取错值
8日期字面量落 UnknownSymbol两边都假
12相邻无运算符（sum(x) B2）严格二叉树 ⇒ 报错产品是静默丢一个操作数；报错更安全

完整 12 条不支持清单与 4 条已知偏差见 docs/m2-engine-design.md §13.5/§13.6 （每条的「怎么补」都给了验证配方）。
